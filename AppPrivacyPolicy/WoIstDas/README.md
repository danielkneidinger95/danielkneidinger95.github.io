# Datenschutzerklärung für „WoIstDas“

Diese Dateien sind für die Veröffentlichung über GitHub Pages vorbereitet:

- `index.html` – Datenschutzerklärung
- `style.css` – Gestaltung

## Wichtig: Text gilt für den beschriebenen Funktionsumfang

Die Erklärung geht davon aus, dass die App:

- keinen Login und kein Benutzerkonto verwendet,
- keinen eigenen Server zur Speicherung von App-Daten verwendet,
- Gegenstände, Container, Kategorien, Notizen und Standorte lokal auf dem Gerät speichert,
- Fotos nur auf ausdrücklichen Wunsch aus der Fotobibliothek auswählt oder mit der Kamera aufnimmt und lokal speichert,
- QR-Codes für Container und Standorte lokal erzeugt und scannt,
- keine Werbung und kein Analytics/Tracking integriert,
- keine Cloud-Synchronisation verwendet,
- keinen Standortzugriff und keine externen Karten- oder Navigationsdienste verwendet.

Sobald z. B. Firebase, Google Analytics for Firebase, Crashlytics, AdMob, Sentry, ein eigenes Backend, Cloud-Synchronisation, ein externer Foto- oder QR-Code-Dienst oder ein anderer externer Dienst eingebaut wird, muss die Datenschutzerklärung entsprechend erweitert werden.
